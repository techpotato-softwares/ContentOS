# Selling ArcForge

## Products

1. **ArcForge for Node** — TypeScript CloudArc
2. **ArcForge for Python** — Python CloudArc (AI-leaning)
3. **Bundle** — both
4. **Agency / Enterprise** — seats + redistribution + support

## Ideal customers (ICP)

### Node SKU
- Agencies delivering AWS backends for clients
- Startups with TS/React stacks needing a Lambda starter
- Teams migrating Nest/Express to serverless

### Python SKU
- AI / ML startups needing FastAPI + auth + AWS
- Data teams adding product APIs
- Consultants selling GenAI MVPs

### Agency tier
- Studios that resell backends inside client projects (not reselling the kit itself without Agency license)

## Channels

1. **Lemon Squeezy / Gumroad** — one-time SKUs + license email
2. **Product Hunt** — launch Node and Python variants
3. **LinkedIn / X** — architecture threads + Loom demos
4. **AWS community / Reddit** r/aws, r/serverless (value-first, not spam)
5. Later: **AWS Marketplace** for Enterprise

## Sales motion

1. Public landing (features + pricing + gap honesty)
2. 3–5 min Loom: clone → docker → login → demo CRUD
3. Private GitHub transfer or zip delivery after payment
4. Optional paid setup day ($800–$1,500)

## Messaging

- “Same CloudArc in TypeScript or Python — buy only what you need.”
- Lead with **RBAC + modules + CDK + dual language**, not “another CRUD boilerplate.”
- Be honest about deferred WAF/Cognito (builds trust).

## What not to promise

- Full ERP / solar vertical
- Multi-cloud runtimes today
- Production RAG out of the box
